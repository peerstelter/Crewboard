# Crewboard

**Task-Management für Event-Crews — mit Telegram-Bot & PWA**

Crewboard ist eine produktionsreife Web-App zur Aufgabenverwaltung für Event-Teams. Crews erhalten Aufgaben direkt über Telegram, erledigen sie per Klick und der Eventleiter sieht alles in Echtzeit im Dashboard.

---

## Features

- **Telegram-Bot Integration** — Aufgaben werden automatisch an Crew-Mitglieder gesendet, Bestätigungen kommen zurück
- **PWA** — funktioniert auf jedem Smartphone ohne App-Installation, offline-fähig
- **Echtzeit-Dashboard** — Eventleiter sehen Live-Status aller Tasks und Crews
- **Rollen & Berechtigungen** — Admin, Teamleiter, Crew-Mitglied
- **Schichtplanung** — Aufgaben können zeitgesteuert und schichtbezogen verteilt werden
- **Docker-Deployment** — läuft per `docker compose up` in Produktion

---

## Tech Stack

| Bereich | Technologie |

| Backend | Node.js · Express |

| Bot | Telegram Bot API |
| Frontend | PWA · Vanilla JS |
| Deployment | Docker · Compose |

Entwickelt für den professionellen Live-Event-Betrieb — von Kongressen und Messen bis zu Theaterproduktionen. Erprobt im Realbetrieb mit mehreren parallelen Crews.
